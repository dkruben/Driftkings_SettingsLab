# AI assistant instructions

Before any substantial work on this project, read [docs/AI_CONTEXT.md](docs/AI_CONTEXT.md). It is the single authoritative source for architecture, commands, validation status and safety rules.

Essentials:

- Never modify an installed game client, the Windows registry, uninstall records or repository protections, and never run an installer, uninstaller or game process on the host, without explicit owner authorisation.
- Never access private signing keys or expose credentials.
- Do not publish, sign or replace releases, or modify `main`, without authorisation.
- Do not treat any realm as the mandatory production reference.
- Do not rerun completed validation without a relevant change or an owner request.
