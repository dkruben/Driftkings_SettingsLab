# 0.1.7-beta.2: EU 2.4.2.0 #1000 owner waiver (realm evidence)

Status: **CONDITIONAL GO — OWNER WAIVER, not independently verified**.

## Owner waiver

The project owner authorised proceeding for EU without an EU 2.4.2.0 #1000 compiled-resource comparison, because the installed EU client update was failing to install. The waiver covers development and local builds only. It does not cover publication, and it is not a verification result.

## Evidence basis (as stated by the owner, and checked where noted)

- Python client source is identical across EU, NA, ASIA and CN. Only `scripts/common/realm.py` differs within the common Python directory (checked against the upstream tree, 2026-11-25).
- ActionScript 3 source (`sources-as3`) is identical across the four production realms.
- All 13 production Gameface bundles are identical between NA #999 and CT #996 (checked against the local CT client; `runtime-evidence/regional/na-ct996-compiled-comparison.json`).
- All 8 NA production SWC inputs are verified against the NA packages (8/8).
- The EU reference `sources/version.xml` (v.2.4.2.0 #1000, realm EU) is pinned by its blob hash `21e0f4a5…78cc7` in the EU profile override.

## Not verified

- EU compiled Gameface bundles (13): bytes not checked against an EU 2.4.2.0 client.
- EU packaged SWC inputs (8): bytes not checked.
- EU native vehicle-marker movie (`battleVehicleMarkersApp.swf`): bytes not checked.
- The local EU client is v.2.4.1.1 #993 at the time of this record; no EU 2.4.2.0 #1000 client was available to the build.

## Integrity controls that remain in force

The EU profile uses the NA pins as an alias, so the build still checks the installed client's bytes. A mismatch refuses the build:

- Gameface patch source hashes (`source_sha256`) and output hashes are enforced by `apply_patch_set`.
- The native vehicle-marker movie digest is enforced by `verify_native_movie` against the client package bytes.
- Flash library digests are enforced against the acquired libraries.
- Build identity (realm, build, revision) must match the EU pin in `production_clients`.

Pins are not relaxed. Only the metadata that names the NA pin file (realm, build, snapshot inside those files) is compared against the reviewed pinned identity instead of the installed client.

## Runtime

Runtime validation for EU is not covered by the NA runtime waiver, which applies to the frozen NA candidate only. A universal candidate needs its own owner decision on runtime validation before any release.

## Restrictions

ASIA and CN remain explicitly unverified: they have no production profile and are refused by the build. RU and PT_RU are permanently excluded and are not in `supported_realms`.
