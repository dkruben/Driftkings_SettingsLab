# PlayerPanelPro

Painel dos jogadores, HP, detecao, loading e TAB num unico componente.

Os ficheiros general.json, playersPanel.json, battleLoading.json,
statisticForm.json e panelShort/Medium/Long/Full.json sao os novos padroes.
A documentacao completa esta em docs/PLAYER_PANEL_PRO.md no projeto.

Para importar as configuracoes antigas do cliente, instalar apenas o wotmod;
os novos JSON sao criados automaticamente. Copiar estes exemplos antes do
primeiro arranque seleciona os padroes em vez de importar a configuracao antiga.
