# Interfaces de hangar

Atualmente não há projetos Flash de hangar ativos. As interfaces usam Gameface,
com recursos em `res/gui/gameface/mods/Driftkings/` e adaptadores Python em
`source/scripts/client/Driftkings/views/hangar/`.

Os projetos Flash antigos estão em `build/flash-archive-20261006/sources/hangar/`.
