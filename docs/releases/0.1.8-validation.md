Ambiente: pastas temporárias fora do repositório. O processo que o helper espera é uma cópia de ping.exe com o nome WorldOfTanks.exe, dentro de uma pasta descartável; não é o jogo. Não houve processos de jogo, diretórios de jogo ativos, chaves privadas, nem alteração ao helper, ao código de produção, aos artefactos assinados ou à gate. O helper e o Installer Python são os reais. Não se verificou descoberta em direto no GitHub nem atualização automática dentro do jogo. A atualização 0.1.7→0.1.8 não instala Driftkings-defaults.zip nem INSTALL.txt: as operações do bilhete são apenas o wotmod, coerente com a instrução de não reinstalar defaults ao atualizar.
