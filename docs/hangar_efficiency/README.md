# HangarEfficiency — retired

Updated: 26 October 2026, beta 0.1.3-beta.2.

The inactive HangarEfficiency panel, its placeholder and legacy presentation have been removed. It has no current settings page, packaged component or supported configuration path. Do not recreate the old `HangarEfficiency.json` file or refer to a `.removed` source folder as a recovery dependency.

Use [vehicle carousel statistics](../vehicle_carousel/README.md), service-record ratings or the hangar Marks of Excellence panel for the available statistics surfaces. Historical implementations remain in Git history; restoring one requires a new component review, current native UI integration and tests.

See the [current project overview](../README.md) and [contribution guide](../CONTRIBUTING.md).
